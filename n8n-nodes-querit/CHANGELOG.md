# Changelog

All notable changes to this package are documented here.

## [0.1.0] - 2026-08-22

### Added

- Querit API-key credential with an authenticated search test.
- Search Web operation with filters, URL normalization, deduplication, and flattened output.
- Fetch Content operation for up to 10 URLs with statuses and metadata.
- Native n8n error handling, secret redaction, `Continue On Fail`, paired items, and AI-tool support.
- Tests, documentation, example workflow, package CI, and provenance publishing workflow.
